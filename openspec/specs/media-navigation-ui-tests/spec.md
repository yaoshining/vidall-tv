# Media Navigation UI Tests

## Purpose

提供媒体库导航流程的 UI 自动化测试覆盖，包括 Tab 切换、剧集详情页、播放历史等交互验证。

## Requirements

### Requirement: 媒体库 tab 切换导航测试
系统 SHALL 提供自动化测试用例，验证首页底部/侧边 tab 导航可正常切换至媒体库 tab、文件源 tab，且各 tab 内容区域正确展示。

#### Scenario: 切换到媒体库 tab
- **WHEN** 测试用例模拟聚焦到媒体库 tab 并触发选择
- **THEN** 内容区域出现"继续播放"或"最近添加"等媒体库相关区域（通过 BY.text 或 BY.id 验证）

#### Scenario: 切换到文件源 tab
- **WHEN** 测试用例模拟聚焦到文件源 tab 并触发选择
- **THEN** 内容区域出现文件源卡片列表或"添加文件源"提示

---

### Requirement: 剧集详情页打开与内容验证测试
系统 SHALL 提供自动化测试用例，覆盖从媒体库点击一个剧集条目跳转至详情页、验证海报展示区、剧情简介、"继续播放"按钮和"集"列表区域均可见的流程。

#### Scenario: 从媒体库跳转到剧集详情页
- **WHEN** 在媒体库列表中点击一个剧集卡片
- **THEN** 跳转至详情页，页面出现剧集标题文本和"继续播放"按钮（通过 BY.text 验证）

#### Scenario: 剧集详情页集列表可见
- **WHEN** 剧集详情页加载完成
- **THEN** 页面底部出现"集"区域，至少包含第1集的标题文本

---

### Requirement: 播放历史页面展示测试
系统 SHALL 提供自动化测试用例，覆盖进入播放历史页、验证列表中包含历史记录条目（封面图/进度/时间信息）的流程；当播放历史为空时验证页面不崩溃。

#### Scenario: 播放历史页有记录时正常展示
- **WHEN** 已有播放记录的情况下导航到播放历史页
- **THEN** 列表中出现至少一条历史记录，包含媒体标题文本

#### Scenario: 播放历史页支持删除操作
- **WHEN** 聚焦到历史记录条目并选中"删除"按钮
- **THEN** 该条目从列表中消失
