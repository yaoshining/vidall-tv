# missing-media-sync Specification

## Purpose

为远程视频、文件源或目录被删除、移动或取消后的失效场景提供目标范围内的安全同步与清理能力。系统通过核验电影、整部剧或文件源已关联的数据库路径，仅清理由远端明确确认不存在的记录，并保留因网络、鉴权、超时或协议限制而无法确认的数据；文件源或目录被移除时在同一事务内清理关联媒体数据与播放记录。所有场景均向 TV 用户提供可感知的进度、结果和页面收敛反馈。

## Requirements

### Requirement: 播放失效后提供同步入口

当播放器明确报告目标视频文件不存在时，电影、季和剧详情页 MUST 提示用户立即同步该目标媒体的信息，而不是直接删除单条记录。

#### Scenario: 电视剧视频无法播放
- **WHEN** 用户从季详情或剧详情播放视频且播放器返回文件不存在
- **THEN** 系统显示“该视频/季/剧可能已不存在，是否立即同步信息？”并提供“立即同步”和“取消”操作

#### Scenario: 电影无法播放
- **WHEN** 用户从电影详情播放视频且播放器返回文件不存在
- **THEN** 系统显示“该电影可能已不存在，是否立即同步信息？”并提供“立即同步”和“取消”操作

#### Scenario: 用户取消同步
- **WHEN** 用户在同步确认提示中选择取消
- **THEN** 系统 MUST 保留现有视频和刮削信息且不发起远程核验

### Requirement: 同步范围限定为目标媒体关联视频

系统 MUST 只核验当前目标电影或当前整部剧在数据库中已经关联的全部视频记录。电视剧同步范围 MUST 覆盖该剧所有季和集，不得仅限于触发失败的单集或当前季。

#### Scenario: 同步电影
- **WHEN** 用户确认同步一部电影
- **THEN** 系统仅加载并核验该电影关联的全部视频记录

#### Scenario: 从季详情同步电视剧
- **WHEN** 用户在任意季详情确认同步
- **THEN** 系统加载并核验该剧所有季的全部关联视频记录

#### Scenario: 不扩大扫描范围
- **WHEN** 系统执行目标媒体同步
- **THEN** 系统不得推导剧根目录、发现新文件、重新刮削或触发整个文件源扫描

### Requirement: 远程目录访问去重并保持范围隔离

系统 MUST 按文件源和父目录对目标媒体的视频路径分组，每个分组至多执行一次远程目录列举，并使用返回的完整文件路径精确核验各记录。远程目录中的非目标媒体文件不得进入删除范围。

#### Scenario: 同目录多个目标视频
- **WHEN** 同一目标媒体的多个视频位于同一文件源和父目录
- **THEN** 系统仅列举该目录一次并分别核验所有目标路径

#### Scenario: 同目录包含其他媒体
- **WHEN** 成功列举的目录同时包含其他电影或剧的视频
- **THEN** 系统仅允许删除当前目标媒体关联且明确不存在的视频 ID

#### Scenario: 路径精确匹配
- **WHEN** 目录中存在名称相似但完整路径不同的文件
- **THEN** 系统不得使用模糊匹配将其视为目标视频

### Requirement: 使用三态存在性判定

系统 MUST 将每个关联视频判定为“存在”“明确不存在”或“无法确认”。只有“明确不存在”的记录可以被删除。

#### Scenario: 文件存在
- **WHEN** 远程目录成功列出且包含与目标记录精确匹配的完整路径
- **THEN** 系统将该记录判定为存在并予以保留

#### Scenario: 文件在成功响应中缺失
- **WHEN** 远程目录成功列出但不包含目标文件完整路径
- **THEN** 系统将该记录判定为明确不存在

#### Scenario: 目录明确不存在
- **WHEN** WebDAV 返回 HTTP 404 或协议适配器返回可稳定识别的目录不存在结果
- **THEN** 系统将该目录组中的目标记录判定为明确不存在

#### Scenario: 无法确认远端状态
- **WHEN** 核验发生网络故障、超时、鉴权失败、不支持协议或其他不能可靠表示不存在的错误
- **THEN** 系统将受影响记录判定为无法确认并保留

### Requirement: 支持安全的部分成功同步

系统 MUST 允许同一次同步中同时出现存在、明确不存在和无法确认的结果，并仅提交明确不存在记录的清理。

#### Scenario: 部分目录不可访问
- **WHEN** 某些目录确认文件缺失而另一些目录因网络错误无法确认
- **THEN** 系统删除已明确缺失的记录并保留无法确认的记录

#### Scenario: 全部记录无法确认
- **WHEN** 所有关联视频均无法确认
- **THEN** 系统不删除任何数据并提示同步失败或暂时无法确认

### Requirement: 同步过程提供阻塞式进度反馈

用户确认后，详情页 MUST 显示阻塞式同步蒙层，展示正在同步状态和已检查数量，并在同步结束前阻止重复播放或重复同步操作。

#### Scenario: 显示同步进度
- **WHEN** 目标媒体同步正在执行
- **THEN** 页面显示加载动画、“正在同步信息”和“已检查 x/y”

#### Scenario: 禁止重复操作
- **WHEN** 同步蒙层处于显示状态
- **THEN** 详情页的播放和同步交互不可再次触发

#### Scenario: 同步完成反馈
- **WHEN** 同步完成且目标媒体仍有有效记录
- **THEN** 页面刷新详情数据并反馈已清理数量以及无法确认数量（若大于零）

### Requirement: 批量清理视频及关联数据

系统 MUST 对明确不存在的视频执行批量清理，删除其刮削关联、播放进度和视频记录，并避免因数据库参数数量限制导致大批量同步失败。

#### Scenario: 删除明确失效视频
- **WHEN** 同步结果包含一个或多个明确不存在的视频 ID
- **THEN** 系统删除这些 ID 对应的刮削关联、播放进度和视频记录

#### Scenario: 不删除保留记录
- **WHEN** 同步结果包含存在或无法确认的视频
- **THEN** 系统不得删除这些视频及其关联数据

#### Scenario: 大批量删除
- **WHEN** 明确不存在的视频数量超过单条数据库语句的安全参数上限
- **THEN** 系统分批完成清理且最终结果与一次原子清理等价

### Requirement: 清理后收敛孤立媒体层级

视频清理完成后，系统 MUST 清理由此产生的孤立刮削元数据，电视剧按集、季、剧层级收敛，电影在没有关联视频时收敛。

#### Scenario: 清空一季但保留整剧
- **WHEN** 某季全部视频均被清理且该剧其他季仍有视频
- **THEN** 系统删除空集和空季但保留该剧及其他季

#### Scenario: 清空整部剧
- **WHEN** 该剧全部关联视频均被清理
- **THEN** 系统删除空集、空季和整部剧元数据，提示用户后退出当前详情页

#### Scenario: 清空电影
- **WHEN** 该电影全部关联视频均被清理
- **THEN** 系统删除该电影的孤立元数据，提示用户后退出电影详情页

### Requirement: 播放器预检判定文件不存在后立即通知

播放器在完整初始化前 MUST 通过预检判定目标文件是否已不存在；预检明确返回不存在（如 404）时，系统 MUST 立即释放旧播放器、重置播放状态并向上层发出文件不可访问事件，避免进入播放兜底后展示无意义的通用错误。

#### Scenario: 预检判定文件不存在
- **WHEN** 播放器预检返回明确的文件不存在结果
- **THEN** 系统释放旧播放器、重置播放与加载状态，并向上层发出文件不可访问事件

#### Scenario: 预检无法确认文件状态
- **WHEN** 预检因网络、鉴权、超时或协议限制而无法确认文件状态
- **THEN** 系统继续原有播放初始化流程

### Requirement: 继续播放入口就地同步失效媒体

从「继续播放」入口进入的播放页 MUST 保留就地同步标志，并在播放器报告文件不可访问时就地执行同步，而不是返回上一页并保留失效记录；切集时 MUST 继续透传该标志。

#### Scenario: 从继续播放进入且文件失效
- **WHEN** 用户从继续播放入口播放且播放器报告文件不可访问
- **THEN** 播放页就地执行同步并刷新，而不是返回上一页
- **AND** 切换到下一集时继续保留就地同步标志

### Requirement: 文件源失效时提供删除与清理入口

当用户在文件浏览器打开一个已失效的文件源根目录（协议明确返回不存在）时，系统 MUST 提示该文件源可能已不存在，并在能确定文件源 ID 时提供删除该文件源及其全部关联数据的操作。

#### Scenario: 打开已失效文件源根目录
- **WHEN** 用户在文件浏览器打开某文件源根目录且协议返回明确不存在
- **THEN** 系统提示文件源可能已不存在，并提供删除文件源操作
- **AND** 仅当能确定文件源 ID 时才显示删除入口

#### Scenario: 确认删除失效文件源
- **WHEN** 用户确认删除该文件源
- **THEN** 系统在一个事务内删除文件源、其目录配置以及全部关联视频、刮削信息和播放记录

#### Scenario: 无法确定文件源 ID
- **WHEN** 文件浏览器未能获得有效文件源 ID
- **THEN** 系统不显示删除入口，仅展示错误信息

### Requirement: 目录取消勾选时同步清理关联媒体数据

当用户在文件源设置中取消勾选已添加的目录时，系统 MUST 在同一事务内清理该目录关联的刮削媒体数据与播放记录，并原子地替换目录配置。

#### Scenario: 取消勾选已添加目录
- **WHEN** 用户在文件源设置中取消勾选某个已添加目录并保存
- **THEN** 系统删除该目录关联的视频、刮削信息和播放记录，并更新目录配置

#### Scenario: 清理与配置替换原子执行
- **WHEN** 目录媒体清理或目录配置替换的任一步失败
- **THEN** 系统回滚整个事务，保留原有媒体记录与目录配置
