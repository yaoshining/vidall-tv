## Decisions

1. 来源契约复用 SearchScope，key 使用本地类别或服务器类型与真实ID。旧空值/字符串路由解析顶部来源；拒绝“无效来源退回本地”，避免静默跨源。配置快照仅内存比较，凭据不进key或日志。
2. VideoServerSearchService 无状态，每请求捕获实例配置。Jellyfin/Emby 用户 Items、Plex 当前 PMS hubs/search 归一化，show 对应 series。相比统一远端协议，保留协议差异可降低兼容风险；返回首批最多100项，无total/hasMore承诺。
3. SearchWorkspaceSession 管理搜索generation与生命周期，比较捕获实例和不可变配置；输入时立即失效而非等防抖触发。历史请求采用独立加载/来源令牌，避免普通关键词更新取消同来源历史。仅检验关键词或来源key不能覆盖同词重试与同ID配置修改，因此不采用。
4. 输入视图按能力切换，结果框架保持复用。服务器详情已接线但仍处于身份隔离修复与验收阶段，禁止用本地详情临时承接服务器结果。具体路由复用已有服务器详情契约。模型修订区分合法初始化与真实配置变更，真实更新/删除在DB写入等待期间即使旧缓存尚未改变也须失效。详情守卫覆盖可见生命周期，不在单次请求finally解除；播放捕获修订并在每次await后及导航前复核active、generation、身份与修订。hide/离页清理监听、show恢复且不重复注册；写失败不得复活旧播放，显式重试可恢复合法入口。
5. 本地拼音保持中文标题优先相关度，通过固定样例集调整规范化、多音词及短首字母边界，不硬套服务器排序。阈值由 #319 的样例验证确定。
6. #320 历史存储使用来源维度隔离，旧全局记录不能复制给每个服务器。实施前检查旧记录是否能可靠归属；无归属证据的记录不进入新来源默认历史，保留备份供回退。相比全局唯一关键词，来源与关键词联合身份避免跨实例覆盖。
7. 实现沿用原六会话，一次分发一个最小项；工程冻结后由独立QA运行，提交推送后增量评审。当前分支只维护本变更产物，不拉入子分支业务代码。

## Risks / Trade-offs

- [生产编译图遗漏] → 不以 UP-TO-DATE 或主机测试替代新服务 ArkTS 实编译；核对编译产物及原始日志。
- [历史和搜索生命周期混用] → 真实页面方法测试延迟历史、输入、清空、换源、离页；异步请求测试真正 reject 而非只返回error状态。
- [环境验证缺口] → CodeLinter exit0 但 SDK not found/uncheck 不算通过；format被IDE单例阻断不杀共享进程，记录未通过。
- [TV与真实协议缺少证据] → 自动测试不替代真机遥控器、实际权限/超时/实例详情验证；目标设备、数据规模及结果需单独记录。
- [有界首批遗漏结果] → 明示限制，不冒充全量，不从不足100项推断没有更多。
