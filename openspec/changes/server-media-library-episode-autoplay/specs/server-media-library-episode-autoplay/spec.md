# Server Media Library Episode Autoplay

## Purpose

定义影视服务器（Jellyfin / Plex）媒体库播放剧集时的自动连播能力：起播时基于服务器当季剧集列表构建播放上下文，播放器在近完播时按既有「自动下一集」机制自动切集，并保证播放进度上报与会话标识的正确衔接，使服务器播放体验与文件源播放保持一致。

## ADDED Requirements

### Requirement: 服务器播放上下文由当季剧集列表构建
系统 SHALL 提供影视服务器播放上下文（`server_media_library` 类型），由当季剧集列表构建：条目按集号升序排列，每条目携带服务器条目 ID、集标题、季号 / 集号、时长与续播位置，并以当前播放条目定位当前索引；当前条目不在列表中时当前索引 SHALL 回退为 0。

#### Scenario: 当季有 3 集时构建包含 3 项的上下文
- **WHEN** 服务器返回当季 3 集的剧集列表，以其中第 2 集为当前播放条目构建上下文
- **THEN** 上下文条目数为 3，条目按集号升序排列，当前索引为 1

#### Scenario: 当前条目不在列表中时索引回退 0
- **WHEN** 传入的当前播放条目 ID 与列表中任何条目都不匹配
- **THEN** 当前索引为 0

#### Scenario: 条目携带切集所需信息
- **WHEN** 构建服务器播放上下文
- **THEN** 每个条目包含服务器条目 ID、集展示标题、季号、集号，上下文包含服务器类型、服务器 ID 等解析流地址所需的服务器标识

### Requirement: 服务器剧集播放入口附带播放上下文
影视服务器的剧集播放入口 SHALL 在进入播放器时附带服务器播放上下文；上下文构建失败（当季集列表拉取失败）时 SHALL 降级为不附带上下文正常播放，不阻塞起播。电影播放 SHALL 不附带剧集上下文。

#### Scenario: 季详情页播放单集时附带上下文
- **WHEN** 用户在季详情页点击某一集播放
- **THEN** 进入播放器的参数携带以当季全部剧集构建的服务器播放上下文，当前索引定位到所点集

#### Scenario: 媒体库继续观看直播放剧集时附带上下文
- **WHEN** 用户在影视服务器媒体库首页对剧集条目点击直播放
- **THEN** 系统解析该剧集所属当季的剧集列表并附带服务器播放上下文

#### Scenario: 详情页剧集播放与跨季续播时附带上下文
- **WHEN** 用户在媒体详情页播放剧集（series 播下一集）或通过跨季「继续上次观看」播放
- **THEN** 进入播放器的参数携带对应季的服务器播放上下文

#### Scenario: 当季列表拉取失败时降级播放
- **WHEN** 起播前拉取当季剧集列表失败
- **THEN** 按无上下文方式正常起播，不弹出错误提示、不阻塞播放

### Requirement: 自动连播机制对服务器上下文生效
播放器内的自动下一集机制 SHALL 对服务器播放上下文生效：近完播（倒计时窗口内）显示「即将播放下一集」浮层并支持取消；倒计时结束自动切到下一集；自动连播开关与倒计时时长 SHALL 复用既有全局设置。

#### Scenario: 近完播显示倒计时浮层
- **WHEN** 服务器剧集播放进入全局倒计时窗口且当季存在下一集，自动连播开关为开
- **THEN** 播放器显示「即将播放下一集 · Xs」浮层，展示下一集标题

#### Scenario: 取消后不再自动切集
- **WHEN** 倒计时浮层展示期间用户点击「取消」
- **THEN** 浮层消失，当前集播完后不再自动切集

#### Scenario: 关闭开关时不自动切集
- **WHEN** 全局自动连播开关为关
- **THEN** 服务器剧集播完不显示浮层、不自动切集

#### Scenario: 当季最后一集播完不切集
- **WHEN** 当前集是当季最后一集
- **THEN** 播完不自动切集、不跨季连播

### Requirement: 自动切集时正确衔接流地址与播放上报
自动切集到下一集时，系统 SHALL 经服务器客户端解析下一集的流地址与请求 Header，生成新的播放会话标识，先对当前集上报播放结束（stopped）再对新集上报播放开始（started），并原地切换播放源；切集失败 SHALL 提示「自动播放下一集失败」并抑制本轮自动切集。

#### Scenario: 倒计时结束自动切换到下一集
- **WHEN** 倒计时结束且下一集存在
- **THEN** 播放器原地切换到下一集流地址并自动开始播放，播放会话标识更新为新会话

#### Scenario: 切集前上报当前集结束
- **WHEN** 自动切集发生
- **THEN** 系统先对当前集以当前播放会话上报 stopped，再对新集上报 started

#### Scenario: 切集失败提示且不循环重试
- **WHEN** 下一集流地址解析失败或切集过程异常
- **THEN** 显示「自动播放下一集失败」提示，本轮不再重试自动切集
