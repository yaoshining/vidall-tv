## Purpose

定义文件源媒体库没有可展示内容时的首页空态行为，使首次使用者获得清晰、聚焦且可通过电视遥控器直接完成配置的启动引导。

## ADDED Requirements

### Requirement: 空媒体库仅展示启动引导
当当前数据源为文件源且媒体库没有可展示内容时，系统 SHALL 展示媒体库启动引导空态及底部统计、扫描与刮削区域，并隐藏“继续播放”和媒体内容分区。

#### Scenario: 首次进入空媒体库
- **WHEN** 用户进入文件源媒体库且媒体库没有可展示内容
- **THEN** 页面展示媒体库启动引导空态及底部统计、扫描与刮削区域
- **AND** 页面不展示“继续播放”或媒体内容分区
- **AND** 用户可以通过底部操作手动扫描或刮削已添加文件源的内容

#### Scenario: 加载完成后仍无内容
- **WHEN** 文件源媒体库加载完成且结果中没有可展示内容
- **THEN** 系统从加载状态切换为媒体库启动引导空态

### Requirement: 空态明确说明建立媒体库的方法
媒体库启动引导空态 SHALL 使用清晰的标题和说明，告知用户可以通过添加文件源或连接影视服务器开始建立媒体库。

#### Scenario: 用户查看空态说明
- **WHEN** 媒体库启动引导空态显示
- **THEN** 用户可以从标题和说明中识别“添加文件源”和“添加影视服务器”两种开始方式

### Requirement: 空态提供直达配置入口
媒体库启动引导空态 SHALL 提供“添加文件源”和“添加影视服务器”两个操作入口；两个入口 MUST 支持电视遥控器聚焦与确认操作，并分别导航至对应的配置页面。

#### Scenario: 打开文件源配置
- **WHEN** 用户聚焦“添加文件源”入口并按下确认键
- **THEN** 系统打开文件源设置页面

#### Scenario: 打开影视服务器配置
- **WHEN** 用户聚焦“添加影视服务器”入口并按下确认键
- **THEN** 系统打开添加影视服务器页面

#### Scenario: 遥控器识别当前操作
- **WHEN** 用户使用遥控器在两个空态入口之间移动焦点
- **THEN** 当前获得焦点的入口具有清晰可见的焦点反馈

### Requirement: 非空媒体库保持完整内容布局
当文件源媒体库存在可展示内容时，系统 SHALL 展示现有的继续播放、媒体内容分区及统计与扫描区域，不得因空态优化而隐藏有效内容。

#### Scenario: 媒体库存在内容
- **WHEN** 文件源媒体库加载完成且存在可展示内容
- **THEN** 系统展示完整的媒体库内容布局
- **AND** 系统不展示媒体库启动引导空态
