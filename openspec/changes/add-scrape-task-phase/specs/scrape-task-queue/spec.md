## ADDED Requirements

### Requirement: 任务展示扫描与准备阶段
系统 SHALL 为任务提供 scanning、preparing、scraping 三个阶段（默认 preparing），并在任务列表展示当前阶段及对应进度；scanning 阶段的任务 MUST 保持等待中状态且不被调度执行。

#### Scenario: 全局任务入队即进入扫描阶段
- **WHEN** 用户启动全局刮削且任务创建
- **THEN** 任务立即以扫描阶段出现在任务列表，并展示已扫描目录进度

#### Scenario: 扫描完成进入准备阶段
- **WHEN** 全局任务的文件扫描完成且任务被标记就绪
- **THEN** 系统将任务切换为准备阶段并开始解析目标，展示已分析视频进度

#### Scenario: 准备完成进入刮削阶段
- **WHEN** 目标准备完成且系统开始逐项目标写入
- **THEN** 任务展示刮削阶段及已完成/总目标进度

#### Scenario: 取消扫描阶段任务
- **WHEN** 用户取消处于扫描阶段的任务
- **THEN** 任务标记为已取消，后续扫描进度更新与就绪操作被忽略，且不执行任何目标写入

#### Scenario: 扫描失败任务进入失败状态
- **WHEN** 全局任务的文件扫描过程失败
- **THEN** 任务进入失败状态且不写入任何目标，用户可清除该任务

#### Scenario: 扫描阶段展示当前扫描上下文
- **WHEN** 任务处于扫描阶段且适配器上报了正在枚举的目录路径
- **THEN** 任务展示文件源类型（如 WebDAV/SMB）、文件源名称、配置的文件夹入口，以及正在扫描的路径；路径超长时以省略号截断中部、保留首尾内容（如 `/根文件夹/爷文件夹/…/abc.mp4`）
- **WHEN** 扫描进入下一文件源或目录完成
- **THEN** 上下文随最新扫描路径更新

#### Scenario: 局部任务保持默认阶段
- **WHEN** 非全局刮削请求入队
- **THEN** 任务使用默认准备阶段并按既有调度行为立即执行

## MODIFIED Requirements

### Requirement: 所有刮削操作异步入队
系统 SHALL 将局部及全局刮削请求创建为后台任务，并在入队后立即将控制权返回界面，不得要求页面等待任务完成；全局刮削 MUST 在文件扫描开始前创建任务。

#### Scenario: 创建后台任务
- **WHEN** 用户完成范围、处理模式及必要确认后启动刮削
- **THEN** 系统立即创建等待中任务并保持页面导航、焦点移动和视频播放可交互

#### Scenario: 离开触发页面
- **WHEN** 用户在任务等待或执行期间离开触发页面
- **THEN** 任务继续由全局队列管理且不访问已销毁页面实例

#### Scenario: 全局刮削先入队后扫描
- **WHEN** 用户启动全局刮削
- **THEN** 系统在启动文件扫描前创建任务，扫描进度通过任务进度展示，且页面在扫描期间保持可交互
