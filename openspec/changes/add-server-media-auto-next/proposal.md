## Why

影视服务器剧集进入播放器时未携带连续剧集上下文，无法复用文件源已有的自动下一集体验。需要让 Jellyfin、Emby 和 Plex 剧集按季集顺序自动连播，并在季末自然进入下一季。

## What Changes

- 为影视服务器剧集建立按季号、集号排序的连续播放上下文。
- 服务器剧集详情页、季详情页和媒体库直播放入口向播放器传递该上下文。
- 自动下一集复用现有开关、倒计时、取消和失败抑制行为。
- 季末自动播放下一季第一集，整剧最后一集不触发自动连播。
- 切集时刷新服务器流地址、认证信息、播放会话和进度上报目标。
- 无法获得完整剧集信息时安全退化为当前单集播放。

## Capabilities

### New Capabilities
- `video-server-episode-autoplay`: 定义影视服务器连续剧集上下文、跨季自动下一集和切源行为。

### Modified Capabilities
- `video-server-detail-pages`: 服务器详情页与季详情页播放单集时必须传递连续剧集上下文。

## Impact

- 影响播放上下文、自动下一集管理器和播放器服务器切源逻辑。
- 影响 Jellyfin/Emby/Plex 剧集列表获取与统一媒体模型映射。
- 影响服务器媒体详情页、季详情页和媒体库条目的播放参数构建。
- 不新增外部依赖，不改变已有自动下一集用户设置。
