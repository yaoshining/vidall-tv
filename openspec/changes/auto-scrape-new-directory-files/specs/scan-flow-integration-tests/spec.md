## ADDED Requirements

### Requirement: 自动刮削新增目录流程的集成测试
系统 SHALL 提供自动化测试用例，验证目录保存后自动刮削任务的端到端流程，覆盖任务自动入队、定向扫描、首次入库筛选、扫描失败与重试等关键路径。

#### Scenario: 新增目录保存后任务自动入队
- **WHEN** 在集成测试中对文件源新增一个目录路径并保存
- **THEN** 系统自动创建刮削任务并入队，TopBar 任务列表中出现新任务

#### Scenario: 定向扫描完成且任务进入刮削阶段
- **WHEN** 自动刮削任务的定向扫描完成且存在首次入库视频
- **THEN** 任务从扫描阶段切换为准备阶段再进入刮削阶段，并展示进度

#### Scenario: 零首次入库视频时任务正常完成
- **WHEN** 新增目录中视频文件的记录在 upsert 前均已存在于数据库
- **THEN** 自动刮削任务正常完成，结果摘要显示零目标

#### Scenario: 扫描失败后可重试且保留定向上下文
- **WHEN** 定向扫描因文件源不可用而失败且用户执行重试
- **THEN** 重试任务的扫描范围与原始任务一致，不扩大为全库扫描

#### Scenario: 别名变化不触发自动刮削
- **WHEN** 在集成测试中仅修改已有目录的别名并保存
- **THEN** 系统不创建任何自动刮削任务

#### Scenario: 自动刮削集成测试可通过参数跳过
- **WHEN** `SKIP_SCAN_TESTS` 参数为 `true`
- **THEN** 自动刮削流程相关集成测试用例不执行，不影响其他套件运行
